Before you start to change any parameter I recommend to save the current parameter into a parameter file.
? Start PIMicroMove (or NanoCapture) ? open the “Device Parameter Configuration” Window ? and “Save edit values as…”

To set the 0µm point in center of the Stage, please change the following parameters for all 4 axes:
CCL 1 ADVANCED
SPA 1 0x07000000 -50                     ; changes the range limit min. to -50µm
SPA 1 0x07000001 50                       ; changes the range limit max. to 50µm
SPA 1 0x07000802 0
SPA 2 0x07000000 -50
SPA 2 0x07000001 50
SPA 2 0x07000802 0
SPA 3 0x07000000 -50
SPA 3 0x07000001 50
SPA 3 0x07000802 0
SPA 4 0x07000000 -50
SPA 4 0x07000001 50
SPA 4 0x07000802 0

Start the Auto Zero Procedure for each axis one at a time:
ATZ 1 50               ; Start Auto Zero axis 1 to 50V piezo voltage = 0µm @~50V
ATZ? 1                   ; Start next ATZ if response = “1”….
ATZ 2 50
ATZ? 2
ATZ 3 50
ATZ? 3
ATZ 4 50
ATZ? 4

Check if the axes are working from -50µm till 50µm and if the 0µm is in center.
Please check also the piezo voltages @-50µm and +50µm:
Piezo Voltage @-50µm: ~ -5V
Piezo Voltage @+50µm: ~ 105V
If anything is working fine, write the parameters into the nonvolatile memory with command: WPA 100

If you have any further question, don’t hesitate to contact me.
